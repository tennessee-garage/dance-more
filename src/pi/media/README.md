# Media

Clips for the **Video** animation, as `<name>.clip.npz`. They are made by
`df2-pi video import` (see [docs/animations.md](../../../docs/animations.md#video-clips))
and are **not committed** - they are large, and usually someone else's
footage, so check its licence before importing. `sync-to-pi.sh` copies this
folder to `~/dance-floor/media` on the Pi along with everything else.
